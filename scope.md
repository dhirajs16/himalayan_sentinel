# Himalayan Sentinel — MVP scope

The original eight-region proof of concept is retained. The current MVP adds an ICIMOD lake inventory, durable report moderation and official alert workflow, while preserving the existing theme and stack.

In scope: public lake polygons/profiles and explainable assessments; explicitly simulated regional trends; private geolocated image reports with development guest verification; admin moderation; jurisdiction-restricted official confirmation; draft, approval, publication, update and resolution; public notices; provider modes/health; audit/export; optional grounded Gemini draft; local SQLite and PostGIS deployment configuration.

A complete demonstration follows citizen report → admin escalation → official confirmation → approved publication → public display → resolution. No numerical score is generated by AI.

Out of operational scope: scientifically validated prediction, inundation/evacuation routing, population exposure without a hazard footprint, real government authorization/onboarding, production identity verification, real SMS/email, municipality datasets and satellite change analysis. These limits are visible rather than populated with invented measurements.

See docs/architecture.md and docs/risk-methodology.md for the implemented design and scientific constraints. This updated document does not assert historical Skill Pack provenance.
